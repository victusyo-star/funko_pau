PUBLISHER HANDOFF
An exported update ZIP contains:
  people.js             Complete replacement data file
  collection.js         Complete replacement data file
  update-summary.json   Entries changed, before/after values, base version
  draft-backup.json     Original base and edited data for recovery/comparison
  READ-ME.txt           Publication instructions

Review the changes and compare the base in draft-backup.json against the
currently published data BEFORE replacing the two JS files. If the public
collection changed after export, reopen the backup in the current editor
and reconcile it instead of uploading an old full replacement blindly.
Upload only people.js and collection.js (plus any avatar assets you prepared).
Do not upload the backup or summary to the public repository.
Wait for GitHub Pages publication, reload the page, and verify the result.
When Pau reopens editing, matching published changes are reconciled with the
retained draft; he can also explicitly discard the draft after publication.

DRAFT RECOVERY
Use the same browser/device to resume a local draft. Private browsing,
clearing browser data, moving the local folder, or changing the site address
may remove or separate browser storage. Download backups regularly. If
storage is blocked or full, the editor displays a warning; changes remain in
memory until you download a backup or leave the page.
Restore accepts only the exported JSON backup, never executable JS.
No automatic cross-device sync or automatic sending/publishing is claimed.
For file:// use, reopen the updated package before reconciling; the browser
cannot check server changes when no server is present.
If a remote source check fails, download a backup and reload before exporting.

VERSION 5.5 — UNIVERSE CARD SPACING / SCALE REFINEMENT
Fixes the title sitting against the rounded top edge by restoring the intended main-card
top inset with the correct CSS specificity. Universe figures now use flexible widths, so
one- and two-figure universes render larger while five-figure universes still fit cleanly.
Figure artwork is also slightly enlarged for a more consistent visual presence. The bottom
owned / wishlist strip, looping behavior, navigation target and all non-Universes views
remain unchanged.


VERSION 5.6 — FIXED UNIVERSE ARTWORK SCALE
Universe carousel figures now use fixed-size slots instead of flexible slots. The visual
scale therefore stays at the Dragon Ball reference size regardless of whether a universe
has one item or many. Sparse universes repeat their own sequence only enough to keep the
loop filled; larger universes keep every figure in the moving rail rather than shrinking
items to fit a card width.

Artwork authoring target for local replacements is 800 x 800 px WebP on a transparent
canvas. Keep the subject centered and bottom-aligned with consistent transparent margins;
do not bake a product box, opaque background or large empty border into replacement art.
A reserved assets/alternates/ folder and its README are included for future replacements.


VERSION 5.7 — SPARSE UNIVERSE DUPLICATION FIX + DOCTOR STRANGE ALTERNATE
Universes with exactly one or two figures now render those real figures once in the
initial visible state instead of visibly duplicating them to pad the rail. Figure slot
size stays fixed at the V5.6 dimensions. Three-or-more-item universes keep the looping
carousel behavior. Doctor Strange now includes a local transparent 800 x 800 WebP
alternate at assets/alternates/doctor-strange-651.webp, wired through catalog.js via
alternateImageUrl and loaded before the remote retailer JPG, with automatic fallback
back to the remote image if the local file is missing or fails.
